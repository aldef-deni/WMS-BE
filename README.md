# ALDEF Backend

Laravel REST API `/api/v1`, Sanctum SPA, MySQL, inventory ledger dan database queue.

Panduan versi, credential lokal, setup, menjalankan PHP 8.4, migration, queue dan pengujian ada di [README proyek](../README.md). Endpoint dan contoh payload ada di [docs/API.md](../docs/API.md).

Gunakan executable `../.runtime/php84/php.exe` pada PC ini untuk semua perintah Composer/Artisan. Test memakai schema `aldef_fulfillment_test`; jangan arahkan ke database operasional.
